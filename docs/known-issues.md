# Known Issues

- When an invalid expression is provided for a Counter delta, the error rendering line wraps when it shouldn't.
- In some cases multiple `$` characters from variables can incorrectly be interpreted as "maths" expressions and produce "Math was not enabled during compilation of the library. Please unable the `maths` feature" notices.

If you encounter issues not listed above, please report them in [the issue tracker](https://github.com/Craig-Macomber/game-tools/issues).
